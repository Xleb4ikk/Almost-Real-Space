Дефект ревизии 1 и исправление (по приёмке фазы 0)

- Писатель трейсов ставил заголовок через AppendLine (CRLF на Windows), а
  строки данных — через '\n'. Файлы получались смешанные; хэши снимались с
  таких файлов.
- Git с `* text=auto` нормализовал EOL при коммите/checkout, поэтому в срезе
  ветки файлы оказались полностью CRLF и хэши ревизии 1 не воспроизводились.
- Исправлено: писатель пишет только '\n' (включая summary), в .gitattributes
  добавлено `baseline/** -text` — эталонные артефакты хранятся байт-в-байт.
- Эталон пересснят на Windows (эталонная машина). Канонические LF-байты новых
  трейсов S1–S5 побайтно совпали с legacy-блобами из git (извлечены
  `git cat-file blob`), то есть паритет «до/после 0.4» подтверждён заново.
