## Компиляция черновиков (Unity 6000.6.0f1): найденные и исправленные ошибки

1. **CS0118 `Spacecraft`** — имя типа совпадает с пространством имён
   `Galilego.Spacecraft`; заменено на алиас `Ship` (3 места).
2. **Гейт внутри зоны получал локальные координаты COM как мировые** (и `Exit`
   писал локальный COM в double-мир → телепорт к началу координат). Высота
   считалась астрономической, зона выходила на следующем кадре. Исправлено:
   локальный COM прокси переводится через `frame.At(t).ToWorld`; гейт и
   double-мир работают в мировых координатах.
3. **Точка корабля vs геометрия T1**: Offset деталей задан от начала сборки,
   низ ног на 5.5 м ниже точки корабля (в игре точка — низ аппарата).
   `ContactZoneProxy` смещает сборку так, чтобы самая низкая точка формы легла
   на точку корабля.
4. **Намотка треугольников `TerrainPatch` давала нормали вниз** — PhysX
   вдавливал тела в рельеф (медленное проседание). Намотка перевёрнута, нормали
   вверх.
5. **`MeshCollider` (convex) не готовит облако вершин**: цилиндр-призма
   перестроена замкнутой (боковины + крышки), с треугольниками.

## Сценарий плоской площадки

Сцена `Assets/ContactZoneSlice.unity` (инструмент `ContactZoneSliceTool`),
проба `ContactZoneSliceProbe` (автостоп, лог раз в секунду):

```
[CZProbe] старт: drop=0.20 м, зона=False
[ContactZone] вход: 0, 360
[CZProbe] t=2 с, зона=True, COM=(0.001, 0.000, 6.060), |v|=0.00000 м/с
... (каждую секунду без изменений) ...
[CZProbe] DONE зона=True, max дрейф=0.00000 м, max |v|=0.00000 м/с, деталей=8
```

Корабль стартует на 0.2 м над поверхностью (касание ≈2 м/с), зона включается,
после касания COM = (0.001, 0.000, 6.060) м (ожидание 6.075), скорость
0.00000 м/с на протяжении 11+ секунд, дрейф от момента осадки нулевой.

Побочно: запуск `OutdoorsScene` (случайный, до открытия сцены среза) прошёл без
ошибок — строка `if (ContactZoneHost.Active) return;` вне зоны инертна.

## Решение по зданиям и ВПП

В срезе — **только рельеф**. Здания/ВПП (SiteBox) подключаются следующим шагом:
сейчас SiteBox по умолчанию даёт габаритные боксы на детали LOD0, и для ног это
неверные невидимые стены; нужны запечённые выпуклые хуллы (`BakedParts`,
`UseConvexMesh`) — это отдельная работа фазы 6. Смешивать её с приёмкой
стояночного сценария не стоит.

## Открытые пункты (из плана, подтверждены)

- Время в зоне стоит (планета не двигается): нужен `VesselStep.AdvanceTime(dt)`
  без орбитальной логики — следующая правка.
- Кориолис не учитывается (~1e-3 м/с² при посадке).
- Тензор инерции в Unity автоматический (не точный из фазы 1).
- Вращение корабля при посадке не моделируется (фаза 8).
