## 1. Цель и главное правило

**Цель.** Игра сама выбирает интегратор корабля по условиям полёта, и выбор подтверждён данными стенда
и тестами игрового пути. Выбор должен быть корректным, воспроизводимым и безопасным: при любом сомнении
остаётся DOP853.

**Главное правило.** Интегратор переключается в игре **только для режима, у которого есть доказательство**
(§5): строка в CSV стенда или результат теста игрового пути, с точной ссылкой. Нет доказательства — режим
остаётся на DOP853, а вопрос идёт владельцу. «Победитель стенда» — это гипотеза, а не разрешение.
Таблица побед по ценам в `PRODUCTION_REPORT.md` содержит методы, которые нельзя использовать в игре
(например, GJ8: при одном шаге 600 с ошибка `3.67e6 м`). Переносить «всё, что выиграло» запрещено.

**Что считается успехом.** Не «побольше методов в игре», а: каждое переключение в игре обосновано строкой
таблицы решений; при выключенных флагах поведение игры побитово прежнее; при включённых — ошибка, события,
детерминизм и аллокации в границах §6; последний этап оформляет включение как решение владельца.

## 5. Правило доказательств

Строка `DECISION_TABLE.md` может получить статус `ENABLE` (включать) только если выполнены все пункты:

1. Есть ссылка на конкретные ячейки или строки CSV стенда (`matrix.csv`, `runs.csv`, `game_control.csv`,
   `chunks.csv` чистого прогона D1) **или** на тест игрового пути, который записал числа в CSV.
   Формат ссылки: `<папка прогона>/<файл>.csv: <problem>,<method>,<goal>[,<колонка>]`.
2. Числа в отчётах берутся из CSV кодом, а не руками (правило TASK.md §10).
3. Ошибка проверена на игровых допусках (`game_control.csv`), а не только на лучшем control из `matrix.csv`.
4. Ветка прошла тесты D4 через `VesselStep`, а не только адаптер стенда.
5. Условия ветки в `IntegratorPolicy` совпадают со строкой таблицы дословно (числа, знаки неравенств).

Статусы: `ENABLE`, `OFF-BY-OWNER` (решение владельца в §3), `NO-EVIDENCE`, `REJECTED` (причина с цифрами),
`DEFAULT` (DOP853). Статус `NO-EVIDENCE` или `REJECTED` для строки, которую §3 велит включить, — стоп (§8).
