# Съёмка: режимы домена по октавам (SlopeDampMode)

Задача: выбрать между `Accum` (домен по высоте) и `Gradient` (домен по крутизне).
На глаз это не читается из чисел — оба проходят приёмку по доле суши и p99,
различается только картинка. Скриншоты нужны, чтобы решить.

## Что и где менять

`Assets/_Project/Profiles/Terrain/EarthLike.asset` → блок `Profile`:

```
NoiseStyle: 1          # 0 = value noise (legacy), 1 = градиентный Перлин
RidgedMode: 0          # 0 = legacy (по умолчанию), 1 = multifractal
SlopeDamp: 0.0         # сила домена
SlopeDampMode: 0       # 0 = Off, 1 = Accum, 2 = Gradient
```

Для съёмки домена `RidgedMode` держим `0`: multifractal сейчас вопрос открытый
(см. раздел «Решения, которые ждут вас»), и мешать два вопроса в одни скриншоты
не надо.

## Что снимать

Инструмент: `Tools/Galilego/Surface authoring/Planet surface window`.

Три сида × два масштаба × четыре режима. Сила домена `SlopeDamp = 0.6` везде,
где режим не `Off`.

| # | Сид | Масштаб (радиус превью) | Режим | Что должно быть видно |
|---|-----|--------------------------|-------|-----------------------|
| 1 | 24334543 | 5000 м | Off | база для сравнения |
| 2 | 24334543 | 5000 м | Accum | деталь уходит из долин и вершин |
| 3 | 24334543 | 5000 м | Gradient | гладкие плато, изъеденные гребни |
| 4 | 24334543 | 120000 м | Off | общая форма |
| 5 | 24334543 | 120000 м | Accum | видна ли потеря детализации на равнинах |
| 6 | 24334543 | 120000 м | Gradient | видна ли детализация гребней издалека |
| 7 | 8932 | 5000 м | Off | второй сид, база |
| 8 | 8932 | 5000 м | Accum | |
| 9 | 8932 | 5000 м | Gradient | |
| 10 | 16851 | 5000 м | Off | третий сид, база |
| 11 | 16851 | 5000 м | Accum | |
| 12 | 16851 | 5000 м | Gradient | |

Три сида — не перебор: T116 показал разброс доли сухи между сидами ±0.041, и
вывод по одному сиду был бы выводом по шуму.

**Позиция камеры фиксированная** во всех двенадцати кадрах, иначе сравнивать
нечего. Сначала снимите `Off` для всех трёх сидов, потом в том же виде `Accum`,
потом `Gradient` — так каждое отличие видно сразу.

## Как судить

- **Accum** должен оставить плато ровными, а гребни и русла долин — изъеденными.
  Если наоборот (гладкие вершины, деталь в средних высотах) — так и должно
  выглядеть, это его определение, и это нормально.
- **Gradient** должен оставить плато и полки гладкими, а всё, что круто, —
  изъеденным. Если разницы с `Accum` не видно, значит `SlopeNorm` насыщается
  не там, и константу порога надо брать по гистограмме (В7а).
- Ожидаемая разница между `Accum` и `Gradient` сильнее всего на **сиде 8932
  вблизи**: там самый высокий разброс p99 между сидами (+9.4% против −4.7% на
  24334543), то есть рельеф разнохарактерный, и различие схем проявится.

## Чего ждать по цифрам (уже помечено в T110)

`+ домен по склону` в T110 совпал с `+ Перлин` по доле суши и p99, и время
оказалось даже меньше. Это означало, что домен в той конфигурации **не работал**
(сточник наклона был привязан к примитиву, и `Value`-путь сбрасывал его в
накопленное значение при выключенном Perlin). Цена режимов после развязки ещё не
измерена — она в T110, строки «+ домен по склону» с раздельно включённым
`SlopeDampMode`.
