# PlannerCheck — независимый стенд математики планировщика

Компилирует `Assets/_Project/Scripts/Trajectory/Planner/*` (чистый C#, без Unity) и
сверяет их с **независимыми** оракулами. Проверки живут в Python; C# только
печатает векторы состояний — ожидаемые значения никогда не берутся из кода под
тестом.

## Запуск

```powershell
dotnet run --project Tools/PlannerCheck -- Tools/PlannerCheck/out.txt
python Tools/PlannerCheck/verify.py Tools/PlannerCheck/out.txt   # Lambert, UniversalKepler, escape, flyby, arc, conic
python Tools/PlannerCheck/verify_diag.py                         # capture geometry, Hohmann prep
```

`verify.py` завершается строкой `FAILURES: 0`, если всё сошлось.
`--project` можно опустить, если запускать из самой папки.

## Оракулы

| Файл | Что делает |
|---|---|
| `oracle.py` | классические элементы → уравнение Кеплера (эллипс/гипербола/парабола) в mpmath, 50 знаков. Другой алгоритм, чем универсальные переменные в игре. |
| `verify.py` | основное: прямое интегрирование ОДУ `scipy` DOP853 (rtol 1e-13), замкнутые формулы асимптот коник `π/2 ± asin(1/e)`, аналитические Хоман/отлёт/захват. |
| `verify_diag.py` | геометрия захвата (асимптота входящей гиперболы) и подготовка орбиты (формулы Хомана). |

## Что покрыто

* `LambertLagrange` / `LambertPrograde`: концы дуги в обе стороны, смысл
  обращения, дуга ровно 180° против аналитического Хомана, гиперболические дуги.
* `UniversalKepler`: позиция/скорость против DOP853, обратимость по времени.
* `EscapeSolver`: энергия `|v|² = v∞² + 2μ/r`, направление и модуль асимптоты,
  радиус периапсиса, «периапсис впереди».
* `FlybyGeometry`: требуемый поворот = угол между v∞, восстановление обеих
  гипербол из периапсиса, семантика `DeficitDv` (слабее коридора SOI — бесплатно,
  сильнее `rpMin` — точный `2·v∞·sin(ε/2)`).
* `CaptureGeometry`: входящая асимптота, ортонормированность осей, `|v_p|`.
* `TransferScanner.ArcMinRadius`: против плотной выборки DOP853.
* `ConicMath`: Δv отлёта/захвата, `e`, `δ = 2·asin(1/e)`, `|Δv| = 2·v∞/e`.
* Сквозные сценарии (`SynthWorld`): Хоман 1→1.524 а.е., наклонная орбита,
  подготовка орбиты, пролёт у Юпитера — цена окна, список импульсов, стыковка
  патч-коник с аналитикой.

## Чего стенд не проверяет

`SpacecraftPhysics`, `GamePlannerPropagator`, `ShootingCorrector` (нужен n-body
прогноз игры), эфемериды и UI. Это отдельная проверка внутри Unity.
