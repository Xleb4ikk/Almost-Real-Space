## Отклонения от утверждённых решений (требуют твоего решения)

1. **Контакты — не XPBD, а sequential impulses (скорость) + проекция проникновения по положению.**
   Причина: при XPBD-контакте проекция проникновения вдоль нормали, в которой гравитация на каждом
   шаге создаёт проникновение, уводила тело по касательной при нулевой скорости — залипание не
   держалось (дрейф 0.58 м за 1 с при стике 30°). Трение кулоновым конусом с накоплением импульса
   по итерациям работает только на скоростном уровне. Стык фазы 2 переведён на тот же скоростной
   уровень (см. п. 2), чтобы решатель был один.
2. **Стыки фазы 2 переписаны.** Было: XPBD-проекция положений по трём точкам. Стало: импульсы на
   скорости + Baumgarte β = 0.2 по ошибке якорей. Причина: смешивание позиционной проекции стыков и
   скоростных контактов нарушало порядок шага; плюс позиционная проекция давала дрейф момента
   импульса 1.5e-3. Итоги фазы 2 пересчитаны: T204 9.96e-15 (как было); T205 1.36e-14 (как было);
   **T206 4.56e-5 м** (было 2.83e-6, порог 1e-3 — проходит); **T207 7.38e-15** (было 3.88e-15, порог
   1e-9 — проходит). Все кейсы фазы 2 зелёные. Принять или откатить.
3. **Рельеф — аналитический (`IContactGround`), не `ITerrainModel`.** Адаптер к `GetHeightMeters` /
   `OrbitingBody` в фазе 3 не подключён: нужна связка со сферической системой координат и вращением
   планеты, это фаза 5/9. Тест T214 использует аналитический камень (λ = 4 м, A = 0.2 м).
   По ТЗ §6.4 — отклонение в объёме, требуется согласие.

## Открытый пункт: T208 (момент импульса системы)

Измерено: |ΔL|/|L0| = **4.03e-5** при dt = 1 мс; при dt = 0.25 мс — 1.4e-5 (масштаб ∝ dt).
Порог 1e-6 задан мной при написании теста, в ТЗ его не было. Диагностика:
- линейный импульс сохраняется до 7e-15 (T207) — стыки парные, это правильно;
- ошибка не зависит от числа итераций (20 и 100 дают одно и то же) и от коэффициента Baumgarte
  (0.2, 0.5, 1.0 дают 4.03e-5) — это не сходимость;
- источник — несогласованность между якорями, по которым считаются импульсы (положения на начале
  шага), и ориентацией, которая интегрируется по конечной ω шага (первый порядок). Попытка
  интегрировать ориентацию по средней ω дала 5.6e-5 — хуже, откатано.

Варианты, выбрать одно:
- **A.** Согласованный по средней ω стык (второй порядок) — отдельная работа, ориентировочно фаза 4.
- **B.** Порог по dt-масштабу (явно, с обоснованием) вместо 1e-6.
- **C.** Оставить T208 красным до фазы 4, закрыть фазу 3 без него.

Я рекомендую **C**: честно зафиксировать, что момент импульса сохраняется с O(dt), и закрыть вместе
с фазой 4, где стыки получают упругость и всё равно переписываются.
