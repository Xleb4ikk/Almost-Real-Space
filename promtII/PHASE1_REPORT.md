## Новые тесты

- **T200 cylinder-inertia** — аналитика цилиндра (7/6/7), поворот на ±90° (перестановка осей), сфера (1), коробка (6.5/5/2.5). Допуск 1e-12.
- **T201 explicit-mass-scaling** — масса 5000 кг и сухая 3000 кг из данных; при половинной массе — COM тот же, тензор ровно вдвое меньше; нулевой размер отвергается исключением. (Утверждено: масса явная, плотность не используется.)
- **T202 point-compat** — точечные детали через `PartDefinition` дают эталон T30 (COM (0.6,0.1,0), 90/1440/1530/60) с допуском 1e-9 и совпадают с прямым путём `Part`.
- **T203 discretized-reference** — T1 дискретизируется по объёму (полярная сетка для цилиндров, декартова для коробки), тензор собирается отдельным проходом. Результат: |ΔCOM| 8e-13 м, max|ΔI_диаг|/I_max 5.9e-5 (порог 1e-3), max|ΔI_вне|/I_max 1.5e-16.

Проверка «есть ли зубы»: при намеренной подмене `r²/2 → r²` для цилиндра падают T200 (Iyy 12 вместо 6)
и T203 (расхождение 5.6e-2). Патч проверен на базе старого среза (код тот же).

   уже нормализует концы строк (`summary.ToString().Replace("\r\n", "\n")`), поэтому его не трогаю.
   Моё предыдущее утверждение, что summary зависит от `Environment.NewLine`, было неверным.
2. **`.gitignore` не покрывает дамп `Test903`.** Строка `/shelf-fix-dump.txt` привязана к корню репозитория.
   Дамп пишется в текущий каталог: при запуске стенда из `Tools/P1bTests` он попадает в
   `Tools/P1bTests/shelf-fix-dump.txt` и не игнорируется. Предлагаю `**/shelf-fix-dump.txt`.
   (При запуске из корня файл попадает под правило; в патче его нет.)
3. **Unity не компилировался здесь** (нет редактора в песочнице). Компиляция и загрузка T1 в сцену
   через редактор — условие закрытия фазы 1 (§14.5 п.4). Проверить на редакторе: сериализацию
   `Vector4 Orientation` по умолчанию и новый enum `PartShape` в `PartDefinition`.
