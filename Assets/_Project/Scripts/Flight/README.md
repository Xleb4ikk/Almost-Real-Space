# Полётная система 6-DOF (Galilego.Flight)

Двигатели и сопла — с реальными точками приложения: в зоне контакта сила идёт в тела PhysX
(`AddForceAtPosition`), вне зоны — 6-DOF по n-body через `VesselStep`. ЦМ и тензор инерции
пересчитываются по текущим массам деталей, топливо выгорает по ступени; ориентация и ω
переезжают через границу зоны без разрыва (`HandoffOut`/`HandoffIn`).

## Клавиши (игрок в корабле)
Газ — Shift/Ctrl; Z — 100 %, X — 0 % · W/S — тангаж, A/D — рыскание, Q/E — крен
I/K, J/L, U/O — РСУ-перемещение · T — SAS (удержание), G — РСУ · F1…F8 — двигатель №n, F9/F10 — все вкл/выкл
Space — зажигание/отделение ступени (теперь и на площадке) · Backspace — аварийный увод САС · Delete — отстрел башни САС

## Настройка
- Планшет в капсуле (`ShipTablet → GameTabletLink`) повторяет управление: панель «УПРАВЛЕНИЕ» — тяга, мастер-выключатель двигателей, ступень; кнопки САС/РСУ — в автопилот модели.
- САС/РСУ: инспектор `SpacecraftBuilder → Flight Systems` (все числа — заглушки порядка Orion).
- Лётные данные двигателей: `EngineSpecs` (Isp у земли, дроссель, подвес, предел давления запуска).
- Сопла с модели: пустышки с `FlightMountMarker` (выхлоп — `transform.forward`).

## Файлы
VesselFlightModel — модель (ЦМ/инерция, тяга, автопилот, САС) · FlightHardware — сопло/команды ·
FlightModelFactory — сборка из чертежа и `FlightMountMarker` · FlightRuntime — ввод и PhysX-режим ·
FlightThrustSource — источник динамики для n-body · AttitudeMath — кватернион из ортов.
