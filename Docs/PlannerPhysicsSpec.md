# Планировщик манёвров — физическая спецификация (Gate 1)

## Задача
Для корабля на орбите тела A найти дату и импульсы перелёта к телу B (в т.ч. с гравитационным манёвром у тела G),
оценить ΔV, выдать план манёвров в системе игры и проверить его в той же n-body физике, что и прогноз на карте.

## Модель и приближения (заявлено до реализации)
| Уровень | Модель | Отступление от «истины» игры | Чем закрыто |
|---|---|---|---|
| Поиск окон | патч-коники, **нулевой радиус сферы действия**, тела на кеплеровых дугах родителя из эфемерид | ошибка прицела ≈ радиус SOI (≈10⁹ м у планеты) | n-body коррекция (ниже) |
| Дуга | Ламберт, один виток, прямое/обратное по нормали родителя | мультивитковые решения не ищутся | заявлено |
| Отлёт | гипербола через точку орбиты корабля с заданной асимптотой, перебор момента на орбите | орбита корабля до импульса — n-body (окно ≤ 3 сут) либо Кеплер (дальше, помечается «ориентировочно») | флаг `Preliminary` |
| Захват | периапсис rp = R + h, импульс против скорости; плоскость — прямая относительно нормали родителя | наклонение орбиты захвата не оптимизируется | заявлено |
| Пролёт | rp из угла поворота δ = asin(1/eᵢₙ)+asin(1/eₒᵤₜ); разность |v∞| закрывается импульсом в периапсисе | нет оптимизации по плоскости пролёта (она однозначна), нет атмосферных эффектов | `Feasible`, `DeficitDv` |
| Уточнение | двухступенчатая стрельба: отлёт (min-norm, затухающий МНК) + TCM1 на 40 % участка; для пролёта ещё TCM2 | импульсная модель (как в `ManeuverPlan`/прогнозе) | прогноз карты = истина |
| Физика | `SpacecraftPhysics` игры: N тел по эфемеридам + барицентрический член + J2 + сопротивление | — | тот же код |

Единицы СИ (м, с, м³/с²), углы — радианы, время — секунды вселенной (double; разрешение ≪ 1 мс на 10¹⁰ с).
Инерциальные оси — оси мировой СК игры. Все формулы — из справочника навыка (F-MAN-01/05/09/10/12, F-NBP-02, F-KEP-09).

## Формулы
* Отлёт/захват (F-MAN-05): Δv = √(v∞²+2μ/r) − √(μ/r); эллипс: − √(μ(1+e)/r).
* Лагранж (F-MAN-09): T(x)=a^{3/2}[(α−sin α)−(β−sin β)]/2, a=1/(1−x²), α=2acos x, β=2asin(λ√(1−x²)); гипербола через acosh/asinh.
  λ² = 2|r₁×r₂|²/((P−D)(r₁+r₂+c)²) при D<0 — устойчивая форма у дуги 180° (прямая 1−c/s теряет разряды как 1/ε²).
* Отлётная гипербола через точку r с асимптотой Ŝ: a·k² − r·sinθ·k − r(1−cosθ)=0, k=√(e²−1); два решения (h=±n̂), выбирается дешёвое.
* Пролёт (F-MAN-10): δ=2asin(1/e), |Δv|=2v∞/e; при разных |v∞| общий периапсис, Δv_p=|v_p,out−v_p,in|.
* Подготовка орбиты (F-MAN-01): два касательных импульса Хомана между круговыми орбитами одной плоскости.
* Корректор: δ = −Jᵀ(JJᵀ+λ²I)⁻¹·(r−r*), λ=10⁻³‖J‖_F. Лестница целей: далёкая точка гиперболы → средняя → периапсис.

## Принятые допуски (объявлены до первого запуска, не ослаблялись)
Кеплер/пропагация 1e-10 отн.; Ламберт vs mp-60 1e-8 (у 180°: 20·u/ε при ε<1e-6); отлёт — энергия 1e-12, направление асимптоты 1e-9;
пролёт 1e-9; пересчёт стоимости независимым кодом 1e-9; промах n-body ≤ 100 м (переход) / ≤ 10 км (гравманёвр, 18 лет полёта).

## Независимые оракулы
mpmath (60 знаков, `kepler_state_mp`) — истина состояний; `propagate_universal` (другой алгоритм) — сквозная проверка дуг;
гиперболическая параметризация Кеплера (cosh/sinh, H=45) — асимптота отлёта/захвата; многостартовый `least_squares` — поиск всех
решений отлёта; SciPy `differential_evolution` по отдельной реализации Ламберта/пролёта (с проверкой своих кандидатов пропагацией!) —
глобальные оптимумы окон; независимый n-body (DOPRI5) — воспроизведение полёта по импульсам плана.
